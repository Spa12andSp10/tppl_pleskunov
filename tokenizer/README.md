# Токенизатор

Это лексический анализатор, который превращает строку исходного кода в последовательность токенов.

## Возможности

Токенизатор может распознавать:

    идентификаторы (последовательность букв, цифр и `_`, не начинающаяся с цифры);
    ключевые слова: `if`, `else`, `while`, `return`, `for`, `def`;
    целые и вещественные литералы;
    строковые литералы в двойных кавычках;
    операторы: `+ - * / = < > == <= >=`;
    разделители: `( ) { } , ;`.

Пробелы, символы табуляции и комментарии (от `#` до конца строки) пропускаются.

Пример:

```
x = y * 2 + z * 3
```

Результат:

    (IDENT, x 1:1)
    (OP, = 1:3)
    (IDENT, y 1:5)
    (OP, * 1:7)
    (INT, 2 1:9)
    (OP, + 1:11)
    (IDENT, z 1:13)
    (OP, * 1:15)
    (INT, 3 1:17)

## Требования

- Python **3.9+**
- `pytest` — для запуска тестов
- `coverage` — для замера покрытия

## Запуск программ

Чтобы запустить программу, сначала ее нужно скачать из репозитория. Затем запустить ее либо в приложении, например, Pycharm или Visual Studio, либо через командную строку, введя эту команду


```bash
python main.py имя_файл_с_данными
```

Или эту, если предыдущая не работает

```bash
python3 main.py имя_файл_с_данными
```

После успешного вычисления программа завершается. 
При ошибке выводится сообщение.

Запуск команды и ее описание можно вызвать с помощью

```bash
python main.py -h
```

```bash
python main.py -help
```

Или эти, если предыдущая не работает

```bash
python3 main.py -h
```

```bash
python3 main.py -help
```

**ВНИМАНИЕ** Не меняйте имя файла! Если его изменить и запустить через командную строку, используя код выше, то произойдет ошибка. Если вы меняете название файла, то пожалуйста меняйте имя и в команде командной строки!


## Запуск тестов

Если у вас не скачан pytest, то установите его. [Подробнее по ссылке](https://pytest-docs-ru.readthedocs.io/ru/latest/getting-started.html)

После установки, в командной строке пропишите команду ниже.

```bash
pytest tests.py
```

**ВНИМАНИЕ** Не меняйте имя файла! Если его изменить и запустить через командную строку, используя код выше, то произойдет ошибка. Если вы меняете название файла, то пожалуйста меняйте имя и в команде командной строки!

Ожидаемый результат — все тесты зелёные.

## Замер покрытия

Если у вас не скачан coverage, то установите его. [Подробнее по ссылке](https://habr.com/ru/articles/448798/)

```bash
coverage html
```

HTML-отчёт появится в `htmlcov/index.html`.

**ВНИМАНИЕ** Тесты и основная программа должны находиться в одной папке, иначе тесты не запустяться!
