# Что нужно сделать, чтобы запустить код?

Нужно скачать main.asm и Makefile, затем в командной строке пробисать `make run`. Первоначально он запуститься с файлом data.txt. Чтобы указать другой файл, нужно прописать `make run FILE=myfile.txt`.

# Какие входные данные?

Формат файла

```txt
5, 3, 2, 6, 1, 7, 4
0, 10, 1, 9, 2, 8, 5
```

Программа не принимает пустые файлы. Программа не работает, если длина двух массивов различна. Программа не работает, если в файле введены не числовые символы.

Программа работает с отрицательными числами, но только с целыми. Попытка использовать в массиве числа с плавающей точкой вызовет ошибку.

# Какие выходные данные?

Ответ будет получен в виде рациональной дроби, например, 4/4 или -20/4.
